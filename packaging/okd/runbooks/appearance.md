# Read the Vesta console

The dashboard brings together protected VMs, connected agents and recent backup jobs. Use **Agents** to check a host's most recent heartbeat and **Virtual Machines** to see the disks available for protection.

When a backup needs attention, open the job and read its status before retrying. For a recovery, start with the VM and the point in time you need. [Daily operations](operations.md) · [Restore a VM](restore.md)
